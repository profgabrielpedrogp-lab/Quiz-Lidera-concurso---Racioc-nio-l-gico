# Negação dos Quantificadores — Lidera Concursos

Material interativo em HTML sobre **Negação dos Quantificadores**, desenvolvido para uso da Lidera Concursos.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie somente estes três arquivos:
   - `.gitignore`
   - `README.md`
   - `index.html`
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O arquivo principal já está com o nome `index.html`, que é o formato esperado pelo GitHub Pages para abrir a página diretamente.

## Estrutura

```text
.
├── .gitignore
├── README.md
└── index.html
```
